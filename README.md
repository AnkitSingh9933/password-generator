# Keyforge — Password Generator UI

A responsive password-generator interface built with React, Vite, and Tailwind CSS v4.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Structure

```text
src/
├── components/
│   ├── CharacterOptions.jsx
│   ├── GenerateButton.jsx
│   ├── Header.jsx
│   ├── PasswordCard.jsx
│   ├── PasswordDisplay.jsx
│   ├── PasswordLength.jsx
│   └── SecurityTips.jsx
├── App.jsx
├── index.css
└── main.jsx
```

## Practice tasks

UI only: password generation, copy-to-clipboard, live slider value, and strength calculation are intentionally left for you to implement.

All component styling uses Tailwind utility classes. `src/index.css` contains the Tailwind import and a small global reset only.
